Common questions

Is this a WordPress plugin?

No. It is a pack of agent workflows and references. Install it for Claude or Codex, then use it on a WordPress project. WordPress and project tooling are not included.

Why do Claude slash commands not appear in Codex?

The namespaced commands belong to the Claude plugin. In Codex, select a complete installed skill or use its name in a natural-language request. See installation.

Does cloning the repository activate the plugin?

No. Claude needs its supported plugin loading flow; manual installation copies skills but does not register plugin commands. Verify activation in the actual session.

Why does the installer reject an existing skill?

It protects existing named DevKit directories. Preview the destination, then use --replace. If a skill has local edits, or a directory was not installed by DevKit, the installer refuses until you copy what you want to keep and add --force. Unrelated skills are preserved.

Why is a custom Codex home not being used?

The installer defaults to ~/.codex/skills. Pass --destination explicitly for a custom CODEX_HOME/skills directory outside the checkout.

What if installation leaves a recovery lock?

Run scripts/recover_distribution.py --destination <skills-dir>. It lists any retained workspace to restore. If it reports only a lock and no installation is running, clear it with --clear-stale-lock. See the recovery example.

Do I need Docker?

Not for reading guides or installing skills. Doctor’s default inventory does not need WordPress bootstrap. Disposable runtime and complete client-evaluation tooling have separate Docker prerequisites.

Can a quick scan prove a security defect?

No. Matches are candidates. Confirm the actor, transformations, controls and reachable sink before classifying a defect.

Does a passing test certify compatibility or WCAG conformance?

No. Results apply to the recorded environment and scope. Accessibility conformance needs representative criterion evidence, including relevant manual and assistive-technology checks.

Does a missing finding mean it was fixed?

No. Report comparison marks absence with resolution unverified. A verified fix needs evidence for the relevant invariant.

Is WordPress DevKit free to use?

Yes. It is available under the MIT License. Keep the copyright and license notices when you share or adapt it. See CHANGELOG.md for what each release includes.

Can the agent edit files during a review?

A review-only request stays read-only. Use a separate, bounded implementation request when you want a change, and a separate deployment scope when appropriate.
